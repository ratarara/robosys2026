# plusコマンド
![test](https://github.com/ratarara/robosys2026/actions/workflows/test.yml/badge.svg)

標準入力から読み込んだ数字を足して出力します。

## 使い方
```
$ git clone https://github.com/ratarara/robosys2026.git
$ cd robosys2026
$ seq 5 | ./plus
15
```

## 必要なソフトウェア
- Python
  - テスト済みバージョン: 3.10〜3.14

## テスト環境
- Ubuntu 24.04 LTS
